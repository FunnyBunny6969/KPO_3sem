### 5. **Алгоритм разбора на двух массивах** (стр. 8-9)
```cpp
// РЕКОМЕНДУЕМЫЙ алгоритм из лекции
bool execute(FST& fst) {
    short* rstates = new short[fst.nstates];
    memset(rstates, 0xff, sizeof(short)*fst.nstates);
    
    for (short i = 0; i < strlen(fst.string); i++) {
        fst.position++;
        if (!step(fst, rstates)) break;  // один шаг автомата
    }
    
    return (fst.rstates[fst.nstates-1] == strlen(fst.string));
}
```

## 🎓 **Ключевые принципы из материалов**

### 1. **Разделение ответственности**
- Лексический анализ → распознавание токенов
- Синтаксический анализ → проверка структуры

### 2. **Использование конечных автоматов**
- Для каждой лексемы свой автомат
- Алгоритм на двух массивах для эффективности O(N)

### 3. **Обработка ошибок**
- Точное указание строки и позиции
- Продолжение работы после ошибок (если возможно)

### 4. **Формат выходных данных**
- Таблица лексем с разбивкой по строкам
- Таблица идентификаторов с дополнительной информацией
